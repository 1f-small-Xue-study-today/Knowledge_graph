Denoising Diffusion Probabilistic Model（去噪扩散概率模型）. The central question is: if we know how to turn data into noise, can we learn to generate data starting from noise?

Learning status: In progress — not yet fully understood / 尚未完全理解

You can start here while VAE is still in progress. Expectation, Gaussian noise, and the idea of a KL penalty are enough for the first four sections. ELBO appears later.

01 / First understand the job

Two processes. Only one is learned.

Real data x₀→Add a little noise→Repeat T times→Almost Gaussian noise xT

This forward process is fixed mathematics. It creates training examples at many noise levels. No neural network is required to add noise.

New Gaussian noise xT→Learned denoising step→Repeat toward t = 0→New generated data x₀

The reverse process is learned. A network sees a noisy sample and its noise level, then predicts a direction that helps construct a slightly cleaner sample.

Generation does not recover a particular original image from arbitrary noise. It draws a new sample consistent with the learned data distribution. Many clean examples can plausibly explain the same noisy observation.

A small world we can see completely

Our data consists of numbers from two groups: half from N(−2,0.35²), half from N(+2,0.35²). Think of them as two kinds of valid examples. The plots show probability distributions over these numbers; they are not image pixels.

02 / Interactive · forward diffusion

Less signal, more noise.

At step t, keep most of the previous signal and add a small amount of independent standard Gaussian noise ξₜ:

xₜ = √αₜ xₜ₋₁ + √βₜ ξₜ,   ξₜ ∼ N(0,1)
αₜ = 1 − βₜ
q(xₜ | xₜ₋₁) = N(√αₜ xₜ₋₁, βₜ)

βₜ is the variance added at this step. αₜ is the fraction of signal variance retained at this step. The accumulated retention is ᾱₜ = α₁α₂⋯αₜ; ᾱ₀ = 1.

Jump directly to any noise level

xₜ = √ᾱₜ x₀ + √(1 − ᾱₜ) ε,   ε ∼ N(0,1)

We can sample xₜ directly from x₀ without computing every earlier step. Here ε represents the combined noise from the forward process, normalized to unit variance. It is not just the last step’s ξₜ.

Teal bars: 800 samples · Orange curve: exact noisy-data density · Gray dashed curve: N(0,1). Fixed plot window: −5 to 5.

Try: move t from 0 to 200. The two groups merge. The known noise schedule makes the end distribution close to N(0,1), the distribution we can easily sample to begin generation.

Demonstration schedule: T = 200, β increases linearly from 0.0001 to 0.08. This short schedule is chosen for this toy lesson, not as an image-training recommendation. The slider holds the same x₀ and ε for each point across t, so it shows coupled marginal samples—not one Markov trajectory with fresh noise at every step.

Why does the direct formula have variance 1 − ᾱₜ?

At t = 1, noise variance is β₁ = 1 − α₁. If the accumulated noise at t−1 has variance 1−ᾱₜ₋₁, multiplying by √αₜ and adding fresh independent noise gives αₜ(1−ᾱₜ₋₁)+βₜ = 1−αₜᾱₜ₋₁ = 1−ᾱₜ. Independent Gaussian noises combine into another Gaussian.

The variance of the added noise conditional on x₀ is 1−ᾱₜ. The overall data variance is ᾱₜ Var(x₀)+(1−ᾱₜ), which is not generally 1 at intermediate steps.
03 / Interactive · a single training example

The network learns the noise we added.

Choose real data x₀, sample a timestep t, draw ε, and construct xₜ. We know the target ε because we generated it. The network receives only xₜ and t (plus a condition, if using a conditional model), not x₀ or the target ε.

ε̂ = εθ(xₜ,t)
Lsimple = E over x₀,t,ε [‖ε − εθ(xₜ,t)‖²]
Known x₀ + sampled ε, t→Construct xₜ→Network sees (xₜ,t)→Compare ε̂ with ε

Here you play the predictor for one example: x₀ = 2, ε = −0.7. This is an illustrative calculation, not a trained network.

Once we have a noise estimate, we can estimate clean data algebraically:

x̂₀ = [xₜ − √(1−ᾱₜ) ε̂] / √ᾱₜ

Try a tiny prediction error at a large t: dividing by a small √ᾱₜ amplifies it. This helps explain why generating in many smaller reverse steps is useful. We do not simply subtract one estimated noise vector and stop.

Can the model identify the exact noise every time?

No. A noisy observation can have many possible clean origins. Under squared-error training, the ideal prediction is E[ε | xₜ,t], the conditional average noise. The button above reveals the actual noise for one example; an inference-time network has no such access. An optimal predictor can still have nonzero training error.

The time input matters because the same numerical xₜ has different meaning at different noise levels. One shared network handles all t; it is not a separate network per step.

04 / Interactive · reverse sampling

Noise becomes a new sample, one step at a time.

Start with xT ∼ N(0,1). At each reverse step, use the noise prediction to calculate a Gaussian mean, then sample:

μθ(xₜ,t) = [xₜ − βₜ εθ(xₜ,t) / √(1−ᾱₜ)] / √αₜ
xₜ₋₁ = μθ(xₜ,t) + √β̃ₜ η,   η ∼ N(0,1)
β̃ₜ = βₜ (1−ᾱₜ₋₁)/(1−ᾱₜ)

This lesson uses the fixed posterior-variance choice β̃ₜ. Other DDPM variance choices exist. At t = 1, β̃₁ = 0 and we add no final noise.

Analytic denoiser demonstration. For our known two-Gaussian data distribution, we can calculate the ideal conditional-mean noise predictor exactly. The controls run the actual DDPM update above, but no neural network is trained here. Even this ideal mean predictor does not make a finite-step Gaussian reverse approximation exact.

Teal bars: 800 generated particles · Orange: target forward density at the current t. Randomness and finite-step approximation produce differences. Repeating the run creates different samples with a similar overall shape.

Why add noise while denoising?

A reverse transition describes uncertainty about a less noisy state. It should be a distribution, not necessarily one deterministic guess. Its learned mean moves toward plausible structure; the variance accounts for stochasticity. Removing all intermediate noise changes the sampler. It does not automatically implement DDIM, which uses a different update.

What does the analytic denoiser actually calculate?

At t, each mixture component has mean ±2√ᾱₜ and variance vₜ = ᾱₜ×0.35²+(1−ᾱₜ). Bayes’ rule gives responsibilities rₖ proportional to the Gaussian density of each component at xₜ. Its score is s(xₜ,t) = Σₖ rₖ(mₖ−xₜ)/vₜ. The ideal noise prediction is −√(1−ᾱₜ)s(xₜ,t). This is available only because we know this toy distribution analytically.

The score connection

sθ(xₜ,t) ≈ ∇xₜ log qₜ(xₜ)
sθ(xₜ,t) = −εθ(xₜ,t)/√(1−ᾱₜ)

The score points locally toward higher probability density. This relationship turns a noise predictor into a score estimate. It is not the gradient of a manually designed geometric distance to a single clean sample.

05 / Connect to what you already know

KL penalties compare reverse transitions.

DDPM can be viewed as a latent-variable model whose hidden variables are the intermediate noisy states x₁,…,xT. The fixed forward process supplies an approximate inference path; the model learns reverse transitions.

pθ(x₀:T) = p(xT) ∏ₜ₌₁ᵀ pθ(xₜ₋₁ | xₜ)
q(x₁:T | x₀) = ∏ₜ₌₁ᵀ q(xₜ | xₜ₋₁)

Using Jensen gives an ELBO on log pθ(x₀). The negative ELBO can be reorganized into:

Terminal prior KL
+ Σₜ₌₂ᵀ E [KL(q(xₜ₋₁ | xₜ,x₀) ‖ pθ(xₜ₋₁ | xₜ))]
− E [log pθ(x₀ | x₁)]

The terminal term is KL(q(xT|x₀) ‖ p(xT)). Each middle term penalizes a learned reverse step for disagreeing with a tractable target posterior. During training x₀ is known, so q(xₜ₋₁|xₜ,x₀) is Gaussian with an exact mean and variance. At generation time x₀ is unknown; the network must infer what is plausible from xₜ alone.

The exact target posterior for t ≥ 2
q(xₜ₋₁ | xₜ,x₀) = N(μ̃ₜ, β̃ₜ I)
μ̃ₜ = [√ᾱₜ₋₁ βₜ/(1−ᾱₜ)] x₀
+ [√αₜ (1−ᾱₜ₋₁)/(1−ᾱₜ)] xₜ

Notice the extra conditioning on x₀. The true reverse q(xₜ₋₁|xₜ), with x₀ unknown, need not be Gaussian; DDPM approximates it with a Gaussian transition.

Why does a KL penalty turn into noise MSE?

For fixed reverse variance σₜ²I, the mean-dependent part of a Gaussian KL is squared mean error divided by 2σₜ². Expressing both means through noise produces:

Mean-dependent KL term = [βₜ² / (2σₜ² αₜ(1−ᾱₜ))] ‖ε − εθ(xₜ,t)‖²

So the variational bound motivates a time-weighted noise-prediction loss. The popular DDPM simple loss drops those weights. It is related to the ELBO, but is not generally the exact negative ELBO. The t = 1 reconstruction likelihood needs separate treatment.

06 / Two different loops

Training samples a timestep. Generation traverses them.

# Training: repeat over minibatches
x0 = sample_real_data()
t = random_integer(1, T, per_example=True)
eps = standard_normal_like(x0)
xt = sqrt(alpha_bar[t]) * x0 + sqrt(1-alpha_bar[t]) * eps
eps_hat = network(xt, t)
loss = mean((eps - eps_hat)**2)
optimizer.zero_grad()
loss.backward()
optimizer.step()

# Generation: network weights are now fixed
x = standard_normal(data_shape)
for t in range(T, 0, -1):
    eps_hat = network(x, t)
    mean = (x - beta[t] / sqrt(1-alpha_bar[t]) * eps_hat) / sqrt(alpha[t])
    eta = standard_normal_like(x) if t > 1 else 0
    x = mean + sqrt(beta_tilde[t]) * eta
return x

The coefficients must broadcast over the data dimensions. This pseudocode uses mathematical timestep indices 1,…,T with ᾱ₀ = 1; map them carefully to zero-based code arrays.

Common mistakes to avoid

  • Using βₜ as a standard deviation. The step’s standard deviation is √βₜ.
  • Using αₜ instead of ᾱₜ in the direct x₀ → xₜ formula.
  • Training on t = 0 with the noise-target formulas: no noise is present and some coefficients divide by zero.
  • Expecting the predictor to recover the exact random noise for every ambiguous input.
  • Subtracting ε̂ directly from xₜ without the schedule coefficients.
  • Changing the inference schedule without adapting the sampler.
  • Assuming diffusion noise level t is physical time. For robot action sequences, diffusion steps and action timestamps are different axes.

What makes a practical neural DDPM?

A denoising network (often a U-Net or transformer), a timestep embedding, a noise schedule, and representative training data. A conditional model also receives context—such as an image, text, or robot observation—at every denoising step. Conditioning is not supplied by the timestep itself.

07 / Active recall

Check the mechanism, not just the name.

1. What is learned in DDPM?

The reverse-process predictor, often εθ(xₜ,t). The standard forward noise schedule and corruption process are fixed.

2. If ᾱₜ = 0.25, x₀ = 2, and ε = −1, what is xₜ?

xₜ = 0.5×2 + √0.75×(−1) ≈ 0.1340. With the exact ε, the clean-data formula returns 2.

3. Does training need to execute all T forward steps for every example?

No. Sample t, then use the direct Gaussian formula for xₜ. Standard simple-loss training also does not run the full reverse chain for every example.

4. Why does generation not need a clean x₀?

The trained network predicts from (xₜ,t). Begin with a new prior sample and repeatedly use the learned transitions. Clean x₀ was needed to construct training targets, not to run generation.

5. Is the simple noise MSE exactly the negative ELBO?

Generally no. The bound has timestep-dependent weights, a terminal prior term, and a reconstruction term. The simple objective deliberately changes that weighting.

6. What did the reverse lab prove—and what did it not prove?

It demonstrated the numerical DDPM updates using a conditional-mean denoiser known analytically for a toy mixture. It did not train a neural network, establish image-generation quality, or make the finite-step Gaussian reverse process exact.

7. Why can’t I remove all sampling noise and call the result DDIM?

DDIM specifies a different schedule-dependent update. Removing the noise term from a DDPM update alone does not produce that algorithm.
